# Student Academic Information 🎓

A simple student project built with HTML, CSS, and JavaScript to manage student academic records.

## Features
- Add student name, roll number, course, semester, subject, and marks
- Automatically assign a grade based on marks
- Search records by student name or roll number
- View total records and average marks
- Delete one record or clear all records
- Save records in browser local storage
- Responsive layout for desktop and mobile

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Add student details in the form.

## Publish with GitHub Pages
1. Upload `index.html`, `style.css`, and `script.js` to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. Wait for deployment and open the website URL shown in the Pages section.

## Grade scale
- 90–100: A+
- 80–89: A
- 70–79: B
- 60–69: C
- 50–59: D
- Below 50: F

## Important note
This is a learning/demo project. Data is stored only in the current browser and is not synchronized between devices. Do not use it to store sensitive or confidential student information.
